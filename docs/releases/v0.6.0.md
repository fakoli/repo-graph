# Repo Graph 0.6.0

## One product, three harnesses

The canonical repository owns the scanner, search engine, viewer, shared skill,
evaluations and architecture decisions. Pi, Codex and Claude Code load the same
product. Existing marketplace and Anvil distributions reference its reviewed
release, replacing copied runtime implementations.

`repo-graph init --harness pi|codex|claude|all` invokes native installation.
`--dry-run` previews commands; user scope is the default. Pi and Claude also
support `--scope project`. Missing selected CLIs and unsupported scopes fail
before installation. Native failures preserve successful installations and
report the failed step. `--source LOCAL_PRODUCT` supports development tests;
`--ref TAG` overrides the remote pin.

Python wheels include the initializer. Native managers fetch plugin resources
from the product source. Existing map/search/serve interfaces and compatibility
map scripts remain supported. No runtime dependency, daemon, hook, provider
setting or inference request is introduced.

## Verification and design

Python regressions, Node geometry/navigation checks and browser workflows pass.
Isolated native Pi, Codex and Claude checks cover the shared skill and caller
directory; Codex/Claude also repeat initialization. Wheel installation and CLI
initialization are checked in a temporary environment. These checks do not
establish new search relevance, call-resolution accuracy or human task gains.

[ADRs](../adr/README.md) record canonical ownership and native installation.
[Polyglot feasibility](../polyglot-feasibility.md) proposes one incremental
fact index with language-specific resolution and evidence-backed candidate
calls. It compares primary research and defines Odoo, Django and polyglot
evaluation gates. Function call analysis is not implemented in this release.

## Upgrade and rollback

Install the 0.6.0 product pin and run initialization for the selected harness.
Existing generated graph/search data needs no migration. Consumer bundles
publish their own pin updates. Do not select the standalone Pi skill and its
bundle distribution twice.

Rollback uses the previous reviewed `v0.5.0` native product pin; generated
artifacts, source repositories and cached models remain available. Claude
support is new in 0.6.0, so disable/remove its plugin through Claude's manager
if returning to the older product.
